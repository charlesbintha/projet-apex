# Checklist de livraison

- [ ] Commit ou tag de release identifié.
- [ ] Cible, workspace, schéma et application confirmés.
- [ ] Aucun secret ou wallet dans le diff.
- [ ] Scripts de base exécutés sans erreur.
- [ ] Aucun objet applicatif invalide.
- [ ] Validation APEXlang réussie.
- [ ] Import DEV réussi.
- [ ] Authentification et navigation testées.
- [ ] Tableau de bord, tickets et workflows testés.
- [ ] Procédure de retour arrière documentée.
- [ ] Diff relu et approuvé.
